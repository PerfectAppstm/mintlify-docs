## Release · Pinned

### Dropstone CLI is now available

**May 29, 2026 · Dropstone Team**

The Dropstone CLI brings the full Dropstone agent into your terminal. Sign in once with your account token, then drive long-context refactors, multi-step code edits, and shell-grade automations without leaving your shell.

**What you get**

- Long-context coding sessions with file awareness and project memory
- Direct access to Dropstone Fast 1.5, Pro 1.5, and Heavy 1.5
- Streaming output, plus prompt caching for repeat work
- Native shell integration: pipe stdin and stdout like any other tool

**Install**

Grab your token from **Settings**, then install the CLI from the downloads page. Full reference lives in the documentation.

<Tip>
  The CLI is now the recommended way to use Dropstone day to day.
</Tip>

## News

### Dropstone IDE is moving to legacy

**May 30, 2026 · Dropstone Team**

The Dropstone IDE moves to legacy status. New development effort shifts to the Dropstone CLI and the dashboard, which together cover the workflows the IDE was originally built for.

**What this means for you**

- The IDE continues to work today and remains available for download for existing users.
- It will no longer receive new features.
- Critical security fixes are still in scope.
- A formal end-of-support date will be announced at least 90 days in advance.

**Recommended next steps**

- Install the Dropstone CLI to access the same models and capabilities from your terminal.
- Use the dashboard for usage, billing, and account management.
- If you rely on a specific IDE feature that does not yet have a CLI equivalent, request support via Discord so the team can prioritize the gap.
