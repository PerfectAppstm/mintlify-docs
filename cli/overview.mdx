The `2am-smt` CLI is the command-line interface for **2AM Database++** (SQL Migration Tool by 2am.tech). Use it to initialize migration projects, test database connections, create and apply migrations, and run ad-hoc SQL scripts — all without opening the desktop application. The CLI is especially useful when you need to integrate database migrations into automated pipelines, CI/CD workflows, or server environments where no GUI is available.

## Installation

Install the CLI globally via npm:

```bash
npm install -g @2amtech/sql-migration-tool
```

Verify the installation:

```bash
2am-smt --version
```

## Global Option

Most commands accept the following option to point to a project outside the current directory:

| Option | Description |
|---|---|
| `-p, --project <path>` | Path to the `configuration.yml` file. Defaults to `./configuration.yml` in the current working directory. |

## Command Summary

| Command | Description |
|---|---|
| `init` | Initialize a new migration project |
| `connection:test` | Test database connection |
| `migrate:new` | Create a new migration file |
| `migrate:to` | Apply or revert migrations |
| `status` | Show migration status |
| `script:new` | Create a new SQL script file |
| `script:run` | Execute a SQL script |

<Note>
  The `2am-smt` CLI is fully non-interactive by default and supports flags like `--auto-apply` to suppress confirmation prompts. This makes it an excellent fit for **CI/CD automation** — you can run migrations as part of your deployment pipeline with no manual intervention required.
</Note>
